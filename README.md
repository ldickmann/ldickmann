## 🧭 About Me

Full-Stack Developer with **real production experience** — I'm co-founder of [**Belezuura**](https://belezuura.com.br), a beauty & fashion e-commerce in Brazil, where I led the migration from Wix Headless to a **100% Shopify Headless architecture** (Next.js 16 · React 19 · TypeScript · Tailwind CSS 4) in 9 months — **without a single minute of downtime**.

Before tech, I spent almost 8 years managing real-estate registration processes — 500+ cases, hard legal deadlines, zero margin for error. That background is why I translate business requirements directly into software.

### ⚡ Impact I've shipped

- 🛒 **Zero-downtime headless migration**: rebuilt a live e-commerce on Shopify Headless — Storefront, Cart & Customer Account APIs with OAuth 2.0 + PKCE, checkout spanning 3 domains (storefront → Shopify → Mercado Pago).
- 📈 **Growth engineering**: technical SEO (dynamic sitemaps, modular robots, SSR/SSG), LGPD-compliant tracking (Google Consent Mode v2), Meta Pixel + GA4 + Merchant Center — restored paid-media attribution across the full funnel.
- 🚀 **Intern → Junior in 25 days** at Lesco Revestimentos, after cutting the priority backlog by **~60%** in the first month with AI-augmented workflows under strict code review.
- ⚡ **+15% performance** and **−8% load time** refactoring Vue.js/Quasar apps; **+40% mobile usability** and **+35% organic indexing** on WCAG-compliant freelance work.
- 🏥 **E-ReceitaSUS v1.1.0**: my own open-source digital prescription system for Brazil's public health system — Flutter app + Node.js/TypeScript API, JWT/JWKS auth, Row Level Security, 3 CI/CD pipelines and a documented security audit (LGPD).
